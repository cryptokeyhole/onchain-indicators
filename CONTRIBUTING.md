# Contributing

Thank you for helping keep this reference accurate.

- **Corrections.** If a definition, formula, threshold or limitation does not match the method shown on the linked chart or guide, open an issue with the entry name and what differs. A pull request with the fix is just as welcome.
- **Clarity.** Suggestions that make an entry easier to understand are welcome, as long as the entry stays short and the formula stays exact.
- **Broken links.** Report any link that no longer opens the chart or guide it names.

Please keep the existing format for each entry (definition, formula, how to read it, limitations, links), write in plain English, and do not add current readings or dated values, since they go out of date.
